## Week 6 (16 February)
**Focus:** Third Iteration: Stakeholder testing preparation, data collection, and evidence generation.
---

### Highlights
- Initiated **structured stakeholder testing**, asking users to complete valuations using their own datasets.
- Configured the tool to **store valuation outputs** (stars, weights, value tags, and metadata) in the database for analysis.
- Provided guidance to stakeholders on:
  - Selecting appropriate use cases
  - Applying weights meaningfully
  - Ensuring value tags are generated for analysis

---

**Outcome:**  
- Began collecting structured valuation responses for analysis.
- Established a dataset suitable for exploring:
  - Relationships between use cases and value tags
  - Differences in prioritisation across stakeholders
- Positioned the project to move from design and refinement into **evaluation and analytical assessment** in the next phase.
